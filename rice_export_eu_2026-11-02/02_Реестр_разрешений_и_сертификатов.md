# Реестр документов и разрешений: казахстанский рис → ЕС

**Проверено 02.11.2026.** В реестре `обязательно` означает требование при указанном условии, а не для всякого риса. Точные тарифы услуг и сроки, которых нет в проверенном публичном источнике, оставлены `не подтверждено`: эти графы заполняются письменным ответом органа/лаборатории. Подробная редактируемая таблица находится в `data/document_register.csv`.

| Документ или процедура | Статус для стандартного шлифованного риса >1 т | Кто отвечает | Основание/условие |
|---|---|---|---|
| Договор, спецификация, инвойс, упаковочный лист | Практически обязательны для сделки и декларации | Экспортёр и импортёр | Таможенная стоимость/идентификация партии, Регламент 952/2013, ст. 70–74. |
| Экспортная декларация РК | Обязательно | Экспортёр/брокер РК | Таможенный кодекс ЕАЭС и процедуры КГД; точный вид декларации проверить. |
| Доказательства происхождения | Обязательно для заявленного происхождения; форма по запросу таможни/договора | Экспортёр | Происхождение и санкционно-тарифные условия; сертификат сам по себе не даёт преференцию. |
| Фитосанитарный сертификат РК | **Условно; для обычного шлифованного риса не подтверждён** | Экспортёр, МСХ РК/территориальная инспекция | В Annex XI 2019/2072 прямо указан семенной рис 10061010; пищевой сырец проверить отдельно. Официальная услуга 3372 — **бесплатно, 2 рабочих дня** в обычном порядке. |
| Протокол лаборатории на идентифицированную партию | Юридически важное доказательство безопасности; перечень тестов по риску, контракту и контролю | Производитель/экспортёр | 178/2002, 396/2005, 2023/915; не является «разрешением ЕС». |
| Прослеживаемость лота | Обязательно | Все пищевые операторы | 178/2002, ст. 18. |
| Учётный номер объекта производства пищевой продукции РК | Условно по виду объекта и санитарному контролю | Производитель, Минздрав РК | [Госуслуга 3275](https://www.gov.kz/services/3275?lang=ru): бесплатно, 5 рабочих дней; проверить, распространяется ли на завод клиента. |
| EORI | Обязательно для импортной таможенной операции | Импортёр/декларант ЕС | 952/2013 и таможенные правила ЕС. |
| AGRIM | **Обязательно свыше 1000 кг нетто** для проверенного кода | Импортёр ЕС | 2016/1237, 2016/1239; условие в TARIC. |
| Импортная декларация и выпуск в свободное обращение | Обязательно | Импортёр/брокер ЕС | 952/2013, ст. 201. |
| Фитосанитарный CHED-PP/TRACES NT | **Условно, прежде всего для регулируемого сырца** | Импортёр/оператор ЕС | 2019/2072, 2017/625; нельзя автоматически требовать для 1006309490. |
| CHED-D/спецконтроль пищевого происхождения | Условно, если рис/страна попадают под действующий усиленный контроль | Импортёр | В консолидированном 2019/1793 на 30.06.2026 Казахстан не указан; проверить новые изменения на дату ввоза. |
| Пищевая маркировка на нужном языке | Обязательно для розничной продажи | Оператор, выводящий товар на рынок | 1169/2011, ст. 9, 15; для опта и B2B применимость уточнить по упаковке и каналу. |
| Процедуры HACCP и гигиены | Обязательно у пищевых операторов; **не отдельный сертификат** | Производитель и импортёр по своей деятельности | 852/2004, ст. 5. |
| ISO 22000 / FSSC 22000 / IFS Food / BRCGS | Добровольно по требованию покупателя | Производитель | Частный стандарт, не универсальное условие таможни ЕС. |
| GlobalG.A.P. | Добровольно/по требованию покупателя | Хозяйство | Частный стандарт, уместен лишь по выбранной цепи поставки. |
| Organic / halal | Только если товар заявлен как органический/halal или покупатель требует | Производитель/уполномоченный орган | Для organic действует отдельная схема ЕС; без неё слово «organic» использовать нельзя. |

**Не закрыто исследованием:** изменения усиленного контроля после консолидированной редакции 2019/1793 от 30.06.2026 и перечень казахстанских официальных сборов; до продажи импортёр и казахстанский брокер должны письменно сверить эти позиции по полному TARIC-коду и дате ввоза. Заявление «никакого CHED никогда не нужно» было бы столь же неверным, как требование CHED-PP для всех форм риса.
Официальные консолидированные тексты для проверки: [2019/2072 на 15.10.2026](https://publications.europa.eu/resource/cellar/7c3a0700-95b6-11f1-9262-01aa75ed71a1.0005.02/DOC_1), [2019/1793 на 30.06.2026](https://publications.europa.eu/resource/cellar/9ac7df3e-6f76-11f1-ae88-01aa75ed71a1.0008.02/DOC_1).

Для первого лабораторного задания использовать подтверждённые строки приложения I к [консолидированному Регламенту 2023/915 на 19.08.2026](https://publications.europa.eu/resource/cellar/217a3917-ac82-11f1-b9e5-01aa75ed71a1.0007.02/DOC_1): неорганический мышьяк белого непропаренного риса **0,15 мг/кг** (3.4.1.1), кадмий **0,15 мг/кг** (3.2.12.3), свинец **0,20 мг/кг** (3.1.11), никель **1,5 мг/кг** с 01.07.2026 (3.6.11.2), афлатоксин B1/сумма **2/4 мкг/кг** для зерновых продуктов конечному потребителю (1.1.12), охратоксин A **3 мкг/кг** (1.2.10). Для риса на физическую обработку, коричневого и пропаренного риса применяются иные строки. Пестицидные MRL определяются по каждому действующему веществу отдельно.
