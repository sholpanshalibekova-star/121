# Экспорт кызылординского риса в ЕС — комплект исследования

Подготовлено 2 ноября 2026 года. Все документы на русском языке. Главный товарный сценарий — пищевой белый шлифованный рис из Казахстана; сорт, лот, покупатель, объём и предложения перевозчиков не предоставлены.

## Основные файлы

1. `01_Полный_экспортный_отчёт.md` / `.docx` / `.pdf` — юридический вывод, тарифы, лаборатория, 27 рынков, логистика и риски.
2. `02_Реестр_разрешений_и_сертификатов.md` / `.docx` / `.pdf` + `data/document_register.csv` — обязательность, условия, органы, источники, подтверждённые/неподтверждённые цены и сроки.
3. `03_Финансовая_модель.xlsx` + `03_Пояснения_к_финансовой_модели.md` / `.docx` / `.pdf` — формулы для 20, 100, 500, 1 000 и 5 000 т и трёх сценариев.
4. `04_База_европейских_покупателей.xlsx` + `data/buyers_30.csv` — 30 проверенных сайтов потенциальных коммерческих организаций; интерес к покупке не подтверждён.
5. `05_План_консалтингового_сопровождения.md` / `.docx` / `.pdf` — восемь этапов, владельцы, контрольные точки и предлагаемая цена наших услуг.
6. `06_Подготовка_к_первой_встрече.md` / `.docx` / `.pdf` — бриф и запрос документов производителю.
7. `07_Дорожная_карта_90_дней.md` / `.docx` / `.pdf` — план запуска по периодам.

`research_progress.md` содержит журнал проверки. `sources/` — полученные ответы официальных API, консолидированные тексты ЕС и статистические таблицы Казахстана. `data/` — расчётные таблицы и результаты проверки сайтов. Скрипты `build_*.py`, `reconcile_market.py` и `fetch_eu_consolidated.py` показывают метод расчёта; сетевые запросы при повторе зависят от доступа API и актуального состояния источников.

## Главные проверенные выводы

- Юридический ввоз обычного пищевого риса Казахстана в ЕС в проверенной тарифной мере не запрещён; конкретная партия требует подтверждения безопасности, классификации и документов.
- Для примера **1006309490** базовая пошлина ЕС **175 €/т**; импортная лицензия AGRIM требуется при весе **свыше 1000 кг нетто**. Беспошлинные квоты не считаются автоматически доступными.
- Для непропаренного белого шлифованного риса предел неорганического мышьяка **0,15 мг/кг** по консолидированному Регламенту (ЕС) 2023/915 от 19.08.2026. Другие подтверждённые пределы — в отчёте.
- По БНС РК валовой сбор риса Кызылординской области в 2025 году **422 333,45 т**, убранная площадь **81 696,6 га**, урожайность **5,17 т/га**. Это не объём шлифованного товарного риса экспортёра.
- Экономическую целесообразность нельзя считать доказанной до получения фактической цены лота, протоколов, предложений перевозчиков и покупателя. Все коммерческие цены в модели — предположения.
